# EARTH TRACE

An intelligent atmospheric change and air quality platform powered by NASA Earth science data, specializing in PM2.5 particulate matter, aerosols, and atmospheric boundary layer dynamics.

## Features
- **3D Atmospheric Visualization**: Interactive 3D globe and atmospheric column simulations.
- **Trend Detection**: Statistical trend analysis of temperature and air quality data.
- **Global Disaster Monitoring**: Near real-time tracking of thermal anomalies and alerts.
- **Report Generation & Print-to-PDF**: Export investigation reports directly as professional, publication-grade NASA Technical Memorandums (PDF) and raw CSV datasets.

## Built With
- **React 19 & TypeScript**: Component-driven architecture with full type safety.
- **Vite 8**: Optimized build tooling.
- **Three.js**: WebGL-powered 3D spatial visualization.
- **Tailwind CSS v4**: Modern, responsive styling system.
- **Google Gemini API**: Grounded AI analysis for scientific interpretation.

## Getting Started
1. Clone the repository.
2. Install dependencies: `npm install`.
3. Run the development server: `npm run dev`.
